ICU 溝通平板 V2.9｜譫妄數字注意力修正版

本版新增／修正：
- 互動定向模式新增「🔢 譫妄數字注意力」。
- 依護理端回饋設為兩組：
  1. 第一組：6 8 5 9 8 3 8 8 4 7，看到 8 有動作。
  2. 第二組：8 1 7 5 1 4 1 1 3 6，看到 1 有動作。
- 目標數字以紅字顯示。
- 可手動按「下一個數字」，方便護理師依病人狀態控制速度。
- 可記錄：有動作、沒有動作、誤動作、無法配合。
- 紀錄標示「數字注意力互動，不作正式診斷判讀」。
- 保留幼稚稱讚病人版、紅旗白旗、簡化撿紅點、簡單有聲書。
- 保留 OOXX、五子棋、簡易大家來找碴、棋子移動、象棋自由玩。
- 保留 Google 翻譯外部連結。
- 保留「重複」、「慢一點」、「聽不懂」大按鈕。
- 保留版權聲明：© 2026 洪苡瑾 版權所有｜請勿二改｜未經授權請勿修改、重製、轉載或二次發布。
- 本工具不判定譫妄陽性或陰性；正式評估仍依單位 CAM-ICU／ICDSC 流程。

GitHub 使用方式：
1. 解壓縮 ZIP。
2. 將 index.html 與 icon.png 一起上傳到 GitHub repository。
3. 若原本已有 index.html，請覆蓋。
4. iPad 使用 Safari 打開網址。
5. 點分享 → 加入主畫面。
