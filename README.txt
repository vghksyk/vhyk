永康榮總｜ICU 溝通平板 V2.9 Final with Icon

本版包含：
- 一般多語模式
- 長者模式
- 互動定向模式
- 非語言互動模式
- 互動題 TTS 分段慢速播放，每段停頓 2 秒
- 抽痰 SVG 圖示
- 「我口渴」
- 報時定位
- iPad / Safari 加入主畫面 icon
- favicon
- icon.png 已包含於同一資料夾

GitHub 使用方式：
1. 解壓縮 ZIP。
2. 將 index.html 與 icon.png 一起上傳到 GitHub repository。
3. 若原本已有 index.html，請覆蓋。
4. iPad 使用 Safari 打開網址。
5. 點分享 → 加入主畫面。
6. 若 icon 沒更新，請重新加入主畫面，或把 index.html 裡 icon.png?v=1 改成 v=2。
