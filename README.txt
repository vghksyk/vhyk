ICU 溝通平板 V2.9｜一般多語＋長者模式＋互動定向模式｜非語言互動修正版

本版新增：
- 互動定向模式新增「非語言互動」。
- 適合無母語者翻譯時，作為外籍病人、聽不清楚、語言不通或無法口語表達病人的互動觀察輔助。
- 題目以視覺辨認與簡單動作為主：
  1. 請點 8
  2. 請點 3
  3. 請找杯子
  4. 請找床
  5. 請找時鐘
  6. 請模仿眨眼
  7. 請握手，再放開
- 非語言互動紀錄顯示「語言限制，未作正式認知判讀」。
- 保留互動題目慢速分段播放。
- 保留一般多語模式、長者模式、慢速語音、抽痰 SVG 圖示、「我口渴」、報時定位。
- 互動定向模式僅作為注意力與定向互動輔助，不判定譫妄陽性或陰性；正式評估仍依單位 CAM-ICU／ICDSC 流程。
