ICU 溝通平板 V2.9｜幼稚稱讚病人版

本版新增：
- 新增「🌟 稱讚病人」。
- 稱讚語設計成更幼稚、更明確、更像得到小貼紙。
- 遊戲答對時回饋改成更正向可愛，例如：答對了耶、你超棒、小星星送給你、拍拍手、今天的小勇士就是你。
- 目的：病人在生病時常感到無力，透過小題目答對後獲得立即稱讚，增加一點點控制感與自信。
- 保留紅旗白旗、簡化撿紅點、簡單有聲書。
- 保留 OOXX、五子棋、簡易大家來找碴、棋子移動、象棋自由玩。
- 保留 Google 翻譯外部連結。
- 保留「重複」、「慢一點」、「聽不懂」大按鈕。
- 保留 TTS 分段慢速播放，每段停頓 2 秒。
- 保留 icon.png，可作為 iPad 主畫面 icon / favicon。
- 本工具不判定譫妄陽性或陰性；正式評估仍依單位 CAM-ICU／ICDSC 流程。

GitHub 使用方式：
1. 解壓縮 ZIP。
2. 將 index.html 與 icon.png 一起上傳到 GitHub repository。
3. 若原本已有 index.html，請覆蓋。
4. iPad 使用 Safari 打開網址。
5. 點分享 → 加入主畫面。
