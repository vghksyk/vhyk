ICU 溝通平板 V2.9｜Final with Icon｜小遊戲版

本版新增：
- 互動定向模式新增「🎮 小遊戲」。
- 小遊戲共 16 題。
- 題目包含找圖案、找物品、數字點選、表情辨認、簡單生活物品辨認。
- 保留 TTS 分段慢速播放，每段中間停頓 2 秒。
- 答對時顯示鼓勵語：「答對，很好。」。
- 答錯時顯示「可以再試一次」，避免病人挫折。
- 紀錄會標示「小遊戲互動，不作正式認知判讀」。
- 保留一般多語模式、長者模式、互動定向模式、非語言互動模式。
- 保留 icon.png，可作為 iPad 主畫面 icon / favicon。
- 本工具不判定譫妄陽性或陰性；正式評估仍依單位 CAM-ICU／ICDSC 流程。

GitHub 使用方式：
1. 解壓縮 ZIP。
2. 將 index.html 與 icon.png 一起上傳到 GitHub repository。
3. 若原本已有 index.html，請覆蓋。
4. iPad 使用 Safari 打開網址。
5. 點分享 → 加入主畫面。
